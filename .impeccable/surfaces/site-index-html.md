## Direction contract

THESIS: An instrument that shows one browser decision travelling three lanes — the page, the code, the model — instead of the generic three-card SaaS dashboard. The flow is the hero; the reader watches a choice move, not a static grid.

OWN-WORLD: Warm-neutral console. Geist for UI and prose, Geist Mono for every table, JSON and measurement (genuine code/data, not costume). Three semantic signal hues own whole lanes: page = azure, code = green, model = burnt amber (also the action accent). Neutral panels, soft offset-blur depth, hairline rules, tabular numerals everywhere, themed selection/scrollbar/caret/focus.

STORY: The reader understands that Jev never writes — it picks a key from a list the code built and returns a probability per option — then feels how fast that is by autoplaying a live run.

FIRST VIEWPORT: Tight title + one-line lede, a slim mode switch, then the three lanes side by side under colored lane headers with a connective flow between them; the step controls sit fixed at the foot with the primary action (next / autoplay) in amber.

FORM: Operate/Read instrument, code-led (no comp round). Signature interaction: on each step a pulse travels page→code→model and the probability bars fill with an ease-out; autoplay makes it a visible rhythm.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
